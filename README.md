# DocScan AI

DocScan AI is a document scanning and management mobile application built with Kotlin and Jetpack Compose. It uses on-device Artificial Intelligence (Google ML Kit) for enhanced document processing and OCR, and Supabase for cloud storage and backend services.

## Project Structure

- **[`docscan-android`](./docscan-android/)**: The Android client application. It provides mobile document scanning capabilities.

## Getting Started

### Prerequisites

- Java JDK 17 (for Android)
- Android Studio

### Android App (docscan-android)

1. Open the `docscan-android` directory in Android Studio.
2. Sync the project with Gradle files.
3. Build and run the app on an emulator or physical device.
